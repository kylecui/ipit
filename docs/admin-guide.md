# TIRE V2 管理员指南

本文档面向 TIRE V2 系统管理员，介绍管理后台的功能和操作方法。

---

## 1. 登录管理后台

1. 访问 `/admin/login`（V2 部署时为 `/v2/admin/login`）
2. 输入管理员账号和密码（默认用户名 `admin`，密码为 `.env` 中的 `ADMIN_PASSWORD`）
3. 登录后进入仪表板

### 1.1 仪表板

仪表板展示系统概览：

- 已注册插件数量与启用状态
- LLM 配置状态
- 最近系统日志
- API 用量摘要

---

## 2. 插件管理

路径：**管理后台 → 插件管理**

### 2.1 查看插件列表

页面列出所有已注册插件（内置 + 社区），显示名称、版本、启用状态、优先级。

### 2.2 启用/禁用插件

点击插件旁的切换按钮即可启用或禁用。禁用后该插件不参与查询。

### 2.3 调整优先级与配置

1. 点击插件名称进入配置页
2. 修改优先级（数值越小越先执行）
3. 编辑插件配置（JSON 格式）
4. 保存

### 2.4 上传社区插件

1. 准备 `.py` 插件文件（需继承 `TIPlugin`，实现 `metadata` 和 `query`）
2. 点击 **上传插件**
3. 系统自动验证插件合约（检查类继承、必要方法、metadata 属性等）
4. 验证通过后，插件保存到 `plugins/community/` 并自动注册

### 2.5 删除社区插件

在插件列表中点击社区插件的 **删除** 按钮。内置插件不可删除。

---

## 3. 共享 API 密钥管理

路径：**管理后台 → 共享 API 密钥**

### 3.1 密钥优先级链

系统按以下顺序查找可用密钥：

```
用户个人密钥 → 管理员共享密钥 → 环境变量 → 无（跳过该插件）
```

### 3.2 设置共享密钥

1. 在页面中找到目标插件
2. 输入 API Key
3. 点击 **保存**

密钥使用 Fernet 加密存储，需确保 `TIRE_FERNET_KEY` 已正确配置。

### 3.3 共享策略

- **允许共享** (`allow_shared`)：开启后，普通用户可使用管理员配置的共享密钥
- **仅限已配置密钥** (`configured_only`)：开启后，没有可用密钥的插件将被跳过（不使用无需密钥的备选方案）

### 3.4 删除共享密钥

点击对应插件的 **删除** 按钮。

### 3.5 使用统计

页面显示每个共享密钥近 30 天的调用次数。

---

## 4. 个人 API 密钥

路径：**管理后台 → 我的 API 密钥**

普通用户和管理员均可为自己配置个人密钥。个人密钥优先级最高，使用个人密钥的查询结果仅该用户可见。

页面显示：
- 已配置的个人密钥
- 各插件的共享密钥可用状态
- 个人调用统计

---

## 5. LLM 设置

路径：**管理后台 → LLM 设置**

### 5.1 个人 LLM 配置

用户可配置自己的 LLM：
- API Key
- 模型名称（如 `gpt-4o`）
- Base URL

也可选择使用管理员分配的共享 LLM 配置。

### 5.2 共享 LLM 配置（仅管理员）

1. 点击 **创建共享 LLM 配置**
2. 填写名称、API Key、模型、Base URL
3. 保存后可分配给用户或策略组

管理员可创建多个共享配置，分别分配给不同用户群体。

### 5.3 验证 LLM 连接

点击 **验证** 按钮测试当前 LLM 配置是否可用。

### 5.4 获取模型列表

点击 **获取模型列表** 查看 LLM 提供商支持的模型。

### 5.5 模板回退

当 LLM 不可用（未配置、权限不允许、超时、上游错误）时，系统自动回退为模板报告，确保报告功能始终可用。报告上会显示"模板"或"AI"标签以区分。

---

## 6. 用户管理

路径：**管理后台 → 用户管理**（仅管理员可见）

### 6.1 创建用户

填写用户名、密码、显示名称，可选设为管理员、指定策略组和共享 LLM 配置。

### 6.2 编辑用户

可修改：
- 显示名称
- 管理员标识
- 启用/禁用状态
- 所属策略组
- 共享 LLM 分配

### 6.3 用户级权限

针对每个用户可设置：
- 各插件的使用权限（允许/禁止）
- 是否允许使用个人 LLM

### 6.4 删除用户

点击 **删除** 按钮。不可删除自己。

---

## 7. 策略组管理

路径：**管理后台 → 策略组**（仅管理员可见）

策略组用于批量管理用户权限。

### 7.1 创建策略组

填写名称、描述、优先级。

### 7.2 组级设置

- 分配共享 LLM 配置
- 设置组级插件权限
- 设置组内用户是否允许使用个人 LLM

### 7.3 权限继承

用户的最终权限由以下层级合并决定：

```
用户直接权限 > 策略组权限 > 全局默认
```

---

## 8. 日志查看器

路径：**管理后台 → 日志**

- 实时查看系统日志（SSE 推送）
- 按级别筛选（DEBUG / INFO / WARNING / ERROR）
- 搜索关键字
- 暂停/继续日志流

---

## 9. API 用量统计

路径：**管理后台 → API 用量统计**

### 9.1 插件 API 统计

- 调用总数
- 成功率
- 平均延迟
- 共享调用 vs 个人调用数量

### 9.2 LLM 统计

- 调用总数
- Token 使用量（输入 / 输出 / 总计）
- 各模型调用明细

### 9.3 查看范围

- **管理员**：查看全平台统计
- **普通用户**：仅查看与自己相关的统计

统计数据也可通过 API 获取：`GET /admin/api/usage`

---

## 10. 个人资料

路径：**管理后台 → 个人资料**

- 修改显示名称
- 修改密码（需验证当前密码）
- 查看个人用量摘要
